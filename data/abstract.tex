\begin{cabstract}

城市交通管理实际运作中常常需要对数据进行实时追踪和分析，使用者也越来越喜欢用口语化的表达方式同系统交流。以往使用较多的分析工具大多依靠固定的检索界面和预定的报表样式，造成没有专业背景的用户很难快速找到想要的信息。因此本研究才完成了架构设计，成功地创建出一个依靠大语言模型技术的交通智能代理平台。

整体架构层面，系统采用慢思考机制和快反应机制融合起来的双层运作方式。慢思考这一层次主要依靠本地部署的Qwen3.5-9B大模型来分析用户的自然语言指令，然后判断应该调用哪个工具。而快反应层中则设置了三个具有主要功能的工具，即查询交通实时状况的模块、整理历史数据变化趋势的分析模块、使用PDFormer时空架构进行流量走向预测的模型工具。这两个层次并不是互相割裂的，而是依靠 LangGraph 状态图来彼此联系起来，从而使得推理步骤和具体的执行动作可以在交替推进的过程中，自然而然地建立起一套 ReAct 循环。就具体的部署环境来说，该大模型是依靠vLLM推理框架，在本地GPU服务器上稳定运行的，它所能够容纳的上下文窗口大小，完全可以满足对20KToken长度的支持需求。

本文针对七个应用场景的测试用例进行设计工作，得到共有37个具体的测试项目，主要是从意图识别、工具调度、报告质量、异常处理四个方面来对智能体的表现进行考察。从最终的实验数据反馈来看，智能体对于意图识别的准确率最终稳定在了百分百，并且对于五种不同的排版格式的自然语言时间表达有较好的解析能力。对于传感器查询、拥堵情况判断、交通流量预测、多工具协同操作等各个场景下的相关处理来说，系统都会不断地给出符合要求的结构化中文分析报告。

\end{cabstract}

\begin{eabstract}

In the actual operation of urban traffic management, it is often necessary to track and analyze data in real-time, and users increasingly prefer to interact with the system using natural language expressions. Previously, most analytical tools relied on fixed query interfaces and pre-set report formats, making it difficult for users without a professional background to quickly find the information they wanted. Therefore, this study completed the architecture design and successfully created a traffic intelligent agent platform based on large language model technology.

At the overall architecture level, the system adopts a dual-layer operation method that integrates a slow thinking mechanism with a fast response mechanism. The slow thinking layer mainly relies on the locally deployed Qwen3.5-9B large model to analyze users' natural language commands and determine which tool to call. In the fast response layer, there are three main functional tools: a module for querying real-time traffic conditions, an analysis module for organizing historical data trends, and a model tool using the PDFormer spatiotemporal architecture to predict traffic flow patterns. These two layers are not isolated from each other but are connected through a LangGraph state diagram, so that reasoning steps and specific execution actions can naturally form a ReAct loop during alternating progress. Regarding the specific deployment environment, this large model runs stably on a local GPU server with the vLLM inference framework, and the context window it can accommodate fully meets the support requirements for a length of 20K tokens.

In this study, test cases were designed for seven application scenarios, resulting in a total of 37 specific test items. The evaluation mainly focuses on four aspects: intent recognition, tool scheduling, report quality, and exception handling. According to the final experimental data feedback, the agent's accuracy in intent recognition eventually stabilized at 100\%, and it has good parsing capabilities for natural language time expressions in five different formatting styles. For tasks such as sensor queries, congestion assessment, traffic flow prediction, and multi-tool collaborative operations, the system continuously provides structured Chinese analysis reports that meet the requirements.

\end{eabstract}

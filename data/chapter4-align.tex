\chapter{多模态数据对齐与构建}

在本章中，将详细介绍如何进行多模态数据的采集、预处理以及跨模态时空对齐算法的设计与实现。通过对采集到的交通流量数据进行深入分析，我们构建了一个高质量的数据集，为后续智能体的推理和决策提供了坚实的数据基础。

\section{数据采集与预处理}

本研究实验数据的原始来源为分布在特定区域内的 7 个交通传感器节点，采集时间跨度从 2026 年 1 月 16 日持续至 2026 年 2 月 9 日。原始数据以 jsonl 格式进行存储，记录了每一分钟的细粒度交通状态，包含了机动车流量、非机动车流量及行人流量这三个关键维度。

在初步的数据清洗阶段，本文首先将各节点的分布式原始记录统一解析为结构化的时序对象。考虑到传感器在分钟级采样时容易受到随机噪声干扰，产生非统计性的数据“毛刺”，本文实施了基于时间窗口的聚合策略，利用重采样技术（Resampling）将原始的 1 分钟观测值按 5 分钟步长进行求和，从而在平滑噪声的同时保留了交通流的动态趋势。

为了满足深度学习模型对时序连续性的严格要求，本研究设计了一套鲁棒的时间基准对齐机制。该机制首先通过计算全采样周期内的最小与最大时间戳，构建了一个覆盖全局、步长为 5 分钟的标准化时间网格。随后，将聚合后的节点数据通过多重索引映射（Multi-index Mapping）合并至该基准网格上。针对传感器可能存在的通信中断或瞬时故障导致的数据缺失问题，本文采用了全零填充逻辑，即在基准网格中自动识别缺失的时间槽（Time Slot）并赋予 0 值，确保了后续空间建模时所有节点在同一时刻均有对应状态。

最后，为适配基于智能体的时空大模型架构及 LibCity 交通仿真标准，处理后的数据被进一步转化为标准化的原子文件格式。其中，主要特征被写入 .dyna 动态数据文件，涵盖了各传感器的时序特征。在输出过程中，数据严格遵循先按时间索引排序、同时间步下按实体 ID 升序的逻辑进行重组，并生成全局唯一的动态标识符（dyna\_id），确保了数据在输入 PDFormer 模型时的拓扑一致性与时间同步性。与此同时，本文根据传感器间的地理空间拓扑关系生成了 .rel 关系文件，确保了多模态数据在结构上的规范化与统一化。

\section{标准化交通数据原子文件定义}

为了确保多模态交通数据在不同预测任务与模型架构间的通用性与兼容性，本研究采用了标准化的原子文件（Atomic Files）协议进行数据存储。原子文件体系将复杂的交通场景解构为地理空间、实体属性、空间关联以及动态时序四个核心维度，通过相互关联的表结构实现对异构交通数据的统一描述。

首先，地理实体表（.geo）是构建路网拓扑的基础，用于存储传感器或路段的静态属性。每个地理实体由唯一的 geo\_id 标识，并包含其几何类型（如点、线、面）及其在地理坐标系下的坐标信息。在本研究中，7 个传感器的位置被定义为 Point 类型，其坐标遵循 (经度, 纬度) 的标准格式，确保了空间信息的精确映射。与之对应的是关系表（.rel），它记录了实体间的交互逻辑，如路网的邻接关系或空间权重。该文件通过 origin\_id 与 destination\_id 定义了流量传输的路径，为模型捕捉空间局部相关性提供了先验拓扑结构。

数据的核心动态部分存储于状态表（.dyna）中。该表记录了交通实体随时间演化的动态特征，每一条记录均包含唯一的 dyna\_id、时间戳 time 以及关联的实体编号 entity\_id。在本研究中，type 字段被设定为状态预测（state），其属性列涵盖了机动车、非机动车及行人的实时流量。为了满足时序建模的连续性要求，.dyna 文件遵循严格的排序规范，即所有记录首要按实体编号排序，在相同实体下按 ISO-8601 标准格式的时间戳进行升序排列。这种双关键字排序机制保证了模型在读取数据时能够直接提取出完整且有序的时序片段。

此外，配置文件（config.json）作为原子文件体系的元数据中心，起到了描述各表结构与辅助模型初始化逻辑的关键作用。它不仅定义了各列的数据类型（如离散 ID、实数或枚举值），还规定了任务相关的超参数，例如时间片的步长、邻接矩阵的初始化方案以及高斯核计算的阈值。为了提高计算效率，在构建原子文件的过程中，本研究对所有实体 ID 实施了从 0 开始的重映射操作，并确保 .geo 文件中的实体顺序与 .dyna 文件中的索引保持高度一致。这种严谨的协议化定义，为后续智能体在多模态环境下进行稳健的特征融合与协同推理提供了标准化的数据接口。

\section{交通拓扑关系构建与 .rel 文件生成}

在多模态交通数据对齐的过程中，构建传感器节点间的空间拓扑关系是实现时空特征提取的基础。本研究通过计算地理空间坐标间的物理距离，利用高斯核函数（Gaussian Kernel）将物理距离转化为标准化的空间关联权重，从而生成交通大模型所需的 `.rel` 关系文件。

首先，针对 7 个传感器节点的经纬度坐标 $(lon, lat)$，本文采用 Haversine 公式计算任意两节点 $i$ 与 $j$ 之间的球面大圆距离 $d_{ij}$。该公式考虑了地球半径 $R$（取 6371 km）以及纬度变化对经度距离的影响，具体计算公式如下：

$$d_{ij} = 2R \arcsin\left(\sqrt{\sin^2\left(\frac{\Delta \text{lat}}{2}\right) + \cos(\text{lat}_i) \cos(\text{lat}_j) \sin^2\left(\frac{\Delta \text{lon}}{2}\right)}\right)$$

其中，$\Delta \text{lat} = \text{lat}_j - \text{lat}_i$，$\Delta \text{lon} = \text{lon}_j - \text{lon}_i$。

在获得全局距离集合后，为了衡量节点间空间交互的强弱，本文引入了统计学中的标准差 $\sigma$ 作为缩放因子，并利用指数高斯核函数计算节点间的相似度权重 $w_{ij}$：

$$w_{ij} = \exp\left( -\frac{d_{ij}^2}{\sigma^2} \right)$$

在该权重体系下，距离越近的节点其权重越趋近于 1，反之则趋近于 0。为了构建稀疏且高效的交通图网络并剔除弱相关冗余信息，本文设定了阈值 $\epsilon = 0.1$。只有当 $w_{ij} \geq 0.1$ 时，才认为节点 $i$ 与 $j$ 之间存在空间拓扑连接。最终，这些空间关联信息被格式化存储为 .rel 文件，为模型提供了明确的空间先验知识。

\section{跨模态时空对齐算法}

在处理多模态交通数据时，不同模态间的时间粒度不一致与空间参考系差异是核心挑战。本研究设计的对齐算法旨在将文本化的交通描述、时空传感器数值以及潜在的视觉特征映射至统一的表征空间。算法首先建立一个以 5 分钟为基准的时间槽索引，利用全局时间戳将经过聚合后的流量数据与同周期的语义信息进行精准匹配。在空间维度上，算法利用 .rel 文件中定义的拓扑关系，结合传感器的经纬度坐标，通过空间权重矩阵实现不同采集点位的特征对齐。对于 Agent 框架而言，这种对齐不仅是数值上的对应，更是一种语义层面的关联，即将数值型的流量激增现象与文本描述中的异常事件进行映射。通过这种方式，智能体能够在同一个时空上下文中感知到多维度的交通态势，从而实现跨模态信息的深度融合与协同推理。
